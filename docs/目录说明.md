# 目录说明

| 路径 | 用途 |
| --- | --- |
| `app/` | 书库、阅读器、笔记、同步和本地存储源码 |
| `public/fonts/` | 正式字体资源，不再依赖缓存目录 |
| `public/vendor/` | 构建时复制的 PDF 引擎与阅读字体 |
| `src-tauri/` | Windows、Android 原生配置与构建工程 |
| `patches/` | EPUB 分页引擎兼容性修复，安装依赖时自动应用 |
| `tests/books/` | 本地人工回归书籍，不包含在安装包中 |
| `tests/reader-core.test.mjs` | 定位计算与同步冲突回归测试 |
| `sync-service/` | Google 系统浏览器授权回调服务 |
| `docs/` | 接入、构建与交付说明 |
| `releases/0.1.4/` | 最终安装文件、测试说明与校验值 |
| `output/playwright/` | 浏览器验证截图与记录 |
| `db/`、`drizzle/`、`worker/` | 保留的网站后端与数据库代码 |
| `node_modules/`、`src-tauri/target/` | 依赖和原生构建缓存，后续构建仍可复用 |

已将根目录测试书及网页公开目录中的测试 EPUB 移入 `tests/books/`。一次性修复脚本、旧构建日志、失效网页缓存和临时依赖包移入 output/archive/。批量删除被自动审批阻止，因此采用归档；Android 嵌套图标目录暂保留。既有源码、Git 历史、项目配置和测试书原文件保留。
