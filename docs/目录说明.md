# 开发与目录说明

## 源码与资源

| 目录 | 用途 |
| --- | --- |
| `app/` | 界面、阅读内核、本地存储与同步 |
| `app/papery-ui.css` | 当前产品界面样式与组件状态 |
| `public/` | 字体、品牌图标与静态 Google 授权回调页 |
| `assets/brand/` | 应用图标与默认头像的原始素材 |
| `src-tauri/` | Windows、Android 原生工程 |
| `src-tauri/gen/android/app/src/main/res/` | Android 实际使用的图标与资源 |
| `patches/` | 阅读引擎兼容补丁，安装依赖时自动应用 |
| `tests/` | 单元测试与界面核查脚本；私人样书不公开 |
| `site/` | GitHub Pages 项目介绍、下载入口与展示图 |
| `scripts/showcase/` | 原创演示内容、界面截图与展示图排版源文件 |
| `docs/` | 使用与配置说明 |

`public/google-drive-callback.html` 与 `google-drive-callback.mjs` 由 GitHub Pages 静态托管，授权回传绑定发起连接的应用会话。

`build/`、`worker/`、`db/`、`drizzle/` 仍被网页开发或构建配置引用，保留其用途；原生阅读器的本地书库由应用中的本地存储模块管理。

## 构建与交付

`node_modules/`、`src-tauri/target/` 与 Android 构建目录是依赖或缓存，不提交 Git。`output/release-0.1.27/` 保存已确认的安装包和本地核查资料。安装包通过 GitHub Release 分发，不放进源码仓库。

历史测试包、临时回退副本和退役同步服务不参与当前构建。私人书籍、个人配置、授权数据、缓存与截图操作日志不上传 GitHub。

## 图标

应用图标原稿为 `assets/brand/papery-master-square.png`。Tauri 图标工具生成原生平台资源后，`scripts/export-brand.py` 补充网页图标与 Windows ICO 的 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 像素帧。

Android 图标以原生工程 `res/mipmap-*` 下的资源为准。`src-tauri/icons/` 只保留原生配置引用的图标，不存放重复的 Android、iOS 或 Microsoft Store 导出集。

`src-tauri/src/windows_icon.rs` 按窗口 DPI 分别设置任务栏与标题栏图标；检查时需同时核对 EXE 资源和窗口实际加载的尺寸。

## 展示图

展示图来自真实应用界面，使用原创演示书籍与模拟阅读记录。演示内容只用于截图，不放进安装包。

1. 生成最新前端 `out/`，在本机 `3100` 端口提供该目录。
2. 运行 `python scripts/showcase/prepare.py`，生成 `output/showcase/capture.js`。
3. 用 Playwright 执行该截图脚本，输出桌面与窄屏界面到 `site/assets/screens/`。
4. 在本机 `3101` 端口提供仓库根目录，用 Playwright 执行 `scripts/showcase/render.js`。
5. 检查 `site/assets/` 下的三张展示图，再更新 README 与项目首页。

`scripts/showcase/layout.html` 保存展示图的构图与文字，界面画面保留实际截图内容。
