# 目录说明

app/ 为应用代码；public/ 为字体、静态 Google Drive 连接入口等公开资源；patches/ 为阅读引擎修复；src-tauri/ 为原生工程；tests/ 为自动测试，tests/books/ 为不公开的样书；docs/ 为说明；output/release-0.1.7/ 保存本次发布文件、校验值与说明；output/archive/ 保存不参与构建的历史维护资料。

node_modules/ 和 src-tauri/target/ 为构建依赖与缓存。db/、drizzle/、worker/ 为保留的网页后端。用户样书、个人配置、缓存不上传 GitHub。
