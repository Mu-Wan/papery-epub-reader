# Papery Reader 0.1.43

EPUB 竖向阅读更流畅，沉浸阅读拥有更多正文空间。

## 阅读体验

- EPUB 竖向阅读采用原生触摸滚动与惯性，改善细小拖动的响应和连续滑动体验。
- 修复部分 EPUB 在正常下滑时持续上下回弹的问题。
- 修复部分旧式 EPUB 章节出现横向条带的问题。
- 改善章节载入、重新载入及窗口尺寸变化时的阅读位置保持。

## 沉浸阅读

- 工具栏收起后，右上角菜单按钮一并隐藏，不再为按钮预留整行空间。
- 轻点正文中间区域可唤出工具栏，再次轻点即可收起。
- 工具栏显示与隐藏不改变正文区域尺寸，保持原有排版与阅读位置。
- 保留系统安全区域、可调上下边距，以及章节、阅读位置、时间与电量信息。

## 下载

- **Windows**：x64 EXE 安装包，使用 WebView2。
- **Android**：Android 7.0 及以上，arm64 APK，沿用原签名，可覆盖更新。

安装文件与 SHA-256 校验值见 [GitHub 发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.43)。
