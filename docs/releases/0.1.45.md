# Papery Reader 0.1.45

PDF 新增可调排版的文字阅读模式，默认使用羊皮色与细纹纸，改进插图显示、连续翻页与选字标注体验。

## PDF 阅读

- 在“阅读设置 → 阅读模式”中选择“文字阅读”，调整字体、字号、行距、段距和边距，支持分页与连续滚动。
- 连续正文按阅读宽度自然换行，整理原页面行尾、多余中文空格与软连字符，保留标题及段落层次。
- 原版与文字阅读共用 PDF 页码，支持搜索、阅读位置与笔记定位；保留已有笔记的原文关联。
- 缩放时纸张纹理覆盖整个阅读区域，减淡页边阴影。
- 改进文件保存与再次打开，避免部分 PDF 重新进入后出现空文件错误。

文字阅读适用于带文字层的 PDF。扫描版使用原版页面；混合文档的无文字页可切换原版查看。插图、表格、公式与复杂布局以原版页面为准。

## EPUB 与选字标注

- 改善 SVG 插图、响应式图片、编码文件名及部分未列入资源清单的插图显示。
- 快速连续点击翻页区域时逐次执行翻页，减少双击选词对翻页的干扰。
- 鼠标拖选仅在左键完全松开后提交标注，新拖选会取消上一轮待提交的选区。
- 改进 EPUB 正文内部焦点切换时的选区处理。

## 默认纸张

默认采用羊皮色＋细纹纸，已有个人阅读设置继续保留。

## 下载与更新

- **Windows**：x64 EXE 安装包，使用 WebView2。
- **Android**：Android 7.0 及以上，arm64 APK，沿用原签名，可覆盖更新。

升级保留本地书库、阅读设置与笔记。已保存为空内容的文件需要重新导入原文件。

安装文件与 SHA-256 校验值见 [GitHub 发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.45)。
