# Papery Reader 0.1.28

本次更新集中修复阅读、备份与界面细节。

## 阅读

- EPUB 连续滚动可跨章节接续，修正竖向阅读仅占半屏、返回已卸载章节后正文空白，以及窗口尺寸变化后的定位问题；按需加载邻近章节。
- EPUB 双页模式的中缝固定约 52px，左右边距设置仅调整最外侧空间。
- 修正跨章节后的标注重载、编辑与删除；检查 TXT 跨章搜索、PDF 不同页面尺寸及阅读位置恢复。
- 沉浸模式保留透明的阅读位置、时间与电量信息，深色阅读背景保持文字可读；没有电量数据时显示“—”。
- 搜索输入保留外层边界与焦点，移除内部蓝色矩形框；定位提示改为一次短暂反馈，支持减少动效设置。

## 整理与界面

- 分类支持悬停编辑、双击及 F2 改名；同步更新书籍分类，保留原文件与封面。
- 分类标题固定，仅列表滚动；数量默认靠右，悬停或键盘焦点进入操作区域时为编辑、删除让出空间。
- 修正 Google 连接区域输入框与按钮遮挡，降低滚动条默认存在感。
- 书库构成改为格式排版和分段比例轨道，移除装饰圆球。
- 界面使用 Papery 自绘图标，收掉重复说明与格式标签；调整默认操作按钮圆角和超宽屏笔记行长。

## 备份与默认配置

- Windows 与 Android 共用 `papery-backup` 版本 1 格式，格式版本独立于应用版本。
- 导出以一致快照读取；还原先完整校验，再原子合并。较旧备份保留较新的阅读位置和删除记录。
- 导出前保存未提交的排版修改，修正排版载入时无意义地更新修改时间的问题。
- 备份只迁移书籍与可迁移设置，不包含 Google 客户端 ID、授权令牌、设备标识或缓存。
- 新安装为默认空书库、默认资料、空 Google 客户端 ID，自动同步关闭；安装包不包含演示内容或个人配置。

## 安装与核查范围

- Windows：x64 EXE，中文安装向导，使用 WebView2。
- Android：7.0 及以上，arm64-v8a，沿用项目现有测试签名。
- 类型检查、生产构建及 19 项单元检查通过；阅读、备份、布局和交互状态均完成对应回归。
- Android 模拟器安装版完成系统文件选择、备份还原及保存，核对三种书籍原文件与可迁移数据；Windows 运行实例完成 Android 备份还原核查。
- Windows 原生备份保存对话框尚未完成自动化验证；实体手机与 Windows 7 实机兼容性未作验证结论。

安装包与 `SHA256SUMS.txt` 见 [GitHub 发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.28)。
