# Papery Reader 0.1.50

自0.1.45以来，书库采用直立书脊布局，新增独立主题设置与简体中文离线释义，改善手机阅读操作、夜间纸色和PDF文字加载速度。

## 书库与主题

- 直立书脊按装帧色、高度和厚度区分书籍，纸签显示阅读进度。桌面悬停展开真实封面、点击阅读；手机点按打开封面与管理操作。
- 默认按作者排序，同一作者书籍相邻；可按书名、最近阅读、导入时间或出版年份排列全书库，保留分类管理。
- 界面底色与强调色分别设置，支持预设、自定义、跟随系统及固定日夜模式。标题栏、侧栏与首页协调一致。
- 夜间使用深灰纸色，适配EPUB内部页面、PDF原版与文字模式；回到日间恢复个人纸张设置。

## 手机阅读与离线释义

- 手机继续阅读区将封面、书名与操作并排，进度条置于底部，分类栏更紧凑。
- 阅读工具栏保持单行实色背景，排版和PDF模式切换可直接操作。放大的PDF支持触摸访问左右边缘。
- 弹窗保留圆角并在内部滚动，关闭按钮与末端操作更易触达。
- 划线后自动离线分词并显示简体中文释义，无需选择词汇或联网搜索。内置65,681个简体词条，仅保留简体词形；词库未收录时显示未收录提示。

## PDF与文件兼容

- PDF文字模式首次提取与再次打开提速，复用持久缓存；文件内容变化时重新提取。
- 保留原版与文字模式的页码关联、搜索和笔记定位，正文随排版与窗口自然换行。
- 改善部分旧环境的文件读取与保存后重开，避免空文件读取导致空白页。
- 鼠标按住拖选并停顿时保持选区，松开后再显示标注。

文字模式适用于带文字层的PDF。扫描页、插图、表格、公式与复杂布局可使用原版页面。

## 下载与更新

- **Windows**：x64安装程序，使用WebView2。
- **Android**：Android 7.0及以上，ARM64安装包，沿用原签名。

升级保留本地书库、设置、笔记及阅读记录。已丢失原内容的历史文件需要重新导入。

安装文件与SHA-256校验值见[GitHub发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.50)。
