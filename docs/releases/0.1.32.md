# Papery Reader 0.1.32

本次发布汇总 0.1.29—0.1.32 的阅读性能、标注、笔记时间线与界面调整，安装包已由使用者确认。

## 阅读

- EPUB 直接读取已有书籍 Blob 的 ZIP 目录和所需资源，减少整本文件转换与重复解压。只缓存不可变的原始数据，每次阅读仍使用独立的书籍与资源生命周期，缓存设有容量上限。
- 保留章节顺序、真实章节大小、CFI、阅读位置及笔记／搜索定位算法；保留字体稳定后再测量正文的等待。TXT 继续使用原来的整本文本解析结构，PDF 保留逐页真实尺寸和准确偏移。
- 复用字体资源地址，跳过完全相同的样式提交；PDF 复用同一数据缓冲区的指纹结果。
- 顶部栏与底部栏更紧凑。底部依次显示章节、页码或阅读位置、当前时间、电量；沉浸模式保留透明状态栏。设备未提供电量时显示“—”。
- 高亮与下划线采用更清晰的颜色和适度透明度，统一三种阅读格式的标注表现。
- 纸张提供净白、浅灰、豆绿、牛皮、羊皮、夜读与自定义颜色，以及纯净、纤维纸、细纹纸三种材质。
- EPUB 由外层阅读页统一绘制纸面，内层背景透明，修正双页边距和中缝处的纯色遮挡。PDF 夜读采用页面反色，图片颜色也会变化，恢复浅色纸面后回到原色。

## 整理与界面

- 笔记按年份、月份形成时间线，可继续按书籍、类型和月份筛选。
- 数据页近 7 天视图使用“本周数据”标题，30 天视图保留对应时间范围。
- 打开用户设置中的云同步时保留当前背景页面，不再切换到书库。
- 搜索框使用单层中性焦点边界；侧栏用户入口与导入书籍按钮统一操作材质。
- 删除书籍默认保持中性，悬停或键盘聚焦时显示强调状态。
- 自定义纸张颜色改为整行可点击的圆角色样控件，显示当前色值，保留系统颜色选择器和键盘焦点。
- 浅色主界面底色调整为 `#F9F8F7`，阅读纸面和深色主题沿用原设置。

## 安装与核查范围

- Windows：x64 EXE，中文安装向导，使用 WebView2。
- Android：Android 7.0+，arm64-v8a，版本号 0.1.32 / versionCode 1032，沿用项目现有检查签名，v2 签名验证通过。
- 0.1.31 的 23 项自动用例通过；原、新 EPUB 读取路径离线对照中，12 个章节的数据、60 处进度、60 个笔记锚点，以及搜索结果的定位和摘录一致。
- 0.1.32 前端生产构建和类型检查通过；改动组件 ESLint 为 0 错误。两端安装包均匹配到当前首页、脚本、样式、阅读引擎和纸纹资源。
- 发布包与确认过的 0.1.32 本地检查包字节一致，仅统一下载文件名；SHA-256 已核对。
- 内置前端资源的凭据模式扫描结果为 0，APK 未检出打包的用户数据库。首次打开为默认空书库、默认资料和空 Google 连接配置。
- 本轮未控制 PC、浏览器或手机界面进行测试，使用者安装检查后确认发布。离线数据对照不能代替所有书籍和设备的排版验证；不以此保证所有设备“秒开”，Windows 7 兼容性仍未作实机结论。

备份格式继续使用独立的版本 1，参见[备份格式与兼容性约定](../backup-format.md)。

安装文件与 `SHA256SUMS.txt` 见 [GitHub 发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.32)。
