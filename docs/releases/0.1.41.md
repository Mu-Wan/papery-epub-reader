# Papery Reader 0.1.41

书籍与笔记支持更多分组方式，查找与续读更方便。

## 书库与笔记

- 书架可按作者、书名首字母、出版年份或导入年份分组，支持折叠与筛选分组，并独立设置组内排序。中文书名按拼音首字母归入 A–Z。
- 笔记可按时间、书籍、作者或标注类型分组，支持搜索笔记、书名、作者与章节。
- 修复首页搜索无结果的问题，搜索覆盖整个书库；清除搜索后恢复原分类。
- 修复“最近阅读”不显示书籍的问题，保留已打开书籍与旧阅读记录的续读入口。

## 书籍信息

- 完善 EPUB、PDF、TXT 的作者与出版年份识别，并补充已有书籍缺失的信息。
- 新增书名、作者与出版年份编辑入口。无法可靠识别的信息可手动填写，已编辑的信息保留优先。

## 沉浸阅读

- 阅读菜单按钮与底部状态栏采用透明背景，与纸张纹理自然融合。
- 电池图标随实际电量变化，支持充电状态；设备无法提供电量时显示“—”。

## 下载

- **Windows**：x64 EXE 安装包，使用 WebView2。
- **Android**：Android 7.0 及以上，arm64 APK。

安装文件与 SHA-256 校验值见 [GitHub 发布页](https://github.com/Mu-Wan/papery-epub-reader/releases/tag/papery-v0.1.41)。
