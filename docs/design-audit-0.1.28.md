# Papery 0.1.28 设计核查

## 核查结论

上一版存在直接使用默认图标库、格式数据重复说明、默认操作按钮过度胶囊化、超宽屏笔记行长失控以及搜索定位提示动效过重等缺口。本轮已修正，并对整屏构图、组件材质与交互状态进行检查。

## 逐项结果

| 设计要点 | 当前实现与核查结果 |
| --- | --- |
| 核心气质与构图 | 书库以当前书籍及继续阅读为主角，最近阅读退后；笔记以引用内容为主角；数据页以阅读时长为主角。页面使用不同的构图与密度，保留共同的间距、对齐及圆角尺度。 |
| 不等分与分组 | 书库采用封面、正文信息与较窄的最近阅读区域；数据页采用大数字、局部点阵面及非等宽下区；笔记正文直接落在页面上。书籍列表保留等尺寸封面以支持扫描比较。 |
| 边界与形状 | 普通书籍、笔记及数据内容不使用玻璃或浮层阴影；工具和输入保留克制的可感知边界。默认操作按钮为 12px 圆角，导航与选择控件按用途保留胶囊形。 |
| 文字与图标 | 界面文字计算样式仅 400、600 两档；移除重复格式说明、重复格式徽标及多余空状态文字。界面图标改为项目自绘 SVG，移除默认图标库依赖；品牌及头像沿用已确认的产品资产。 |
| 色彩 | 浅色主题使用指定中性与蓝、橙、绿变量。蓝用于选择和关键数据，绿用于已完成记录，炭黑用于阅读主操作与主数字；普通内容面保持近白层级。 |
| 材质与空间 | 内容卡片计算结果均无阴影、无背景模糊；磨砂用于导航、阅读工具及弹层。沉浸底栏完全透明，无独立磨砂面。 |
| 数据可视化 | 阅读节奏使用点阵，未完成部分使用低对比纹理；书库构成改为主格式排版和细分段比例轨道，移除装饰圆球。 |
| 动效 | 选择指示面以可中断的 transform 动画移动；按钮按下为 scale(.97)。搜索定位提示由多轮发光改为一次 280ms 透明度反馈，并遵守减少动效设置。 |
| 状态与适应性 | 核查默认、悬停、按下、选择、焦点、禁用、加载、空、错误与成功。空书库、3 本、50 本及超长文本分别覆盖 390、1440、2560px；27 组页面组合通过，13 项交互状态检查通过。超宽屏笔记重排并限制行长。 |
| 整屏审视与品牌辨识 | 已查看书库、笔记、数据和阅读整屏截图。主要视觉关系由真实书籍封面、引用内容、阅读位置及实际记录建立；替换名称不能直接替换这些产品关系。此项为视觉审视结论，不属于自动化测试证明。 |

## 核查范围

自动化结果、整屏截图、Windows 运行实例和 Android 模拟器检查分别保留证据。模拟器与窄屏浏览器不替代实体手机的最终验收；色彩约 80% 为构图目标，不将其描述为所有状态逐像素计算后的恒定比例。
