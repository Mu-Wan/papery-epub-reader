从一本书开始

按自己的节奏阅读

EPUB、TXT 可调整排版与主题，PDF 保留原始页面。键盘、鼠标与手机触控，适应不同的阅读场景。

记住读到哪里

保存阅读位置、书签、划线和笔记。书库支持封面、搜索与分类，初次打开是干净的空书库。

本地保存，自主同步

不开启同步也能阅读。完整备份可以导出；配置 Google Drive 后，在设备之间合并书籍与阅读记录。

GOOGLE DRIVE

只需客户端 ID

不需要客户端密钥，也不需要自行部署登录服务。软件“偏好设置 → 数据备份”下方提供完整步骤。

查看详细配置与常见问题 ↗

  1. 在 Google Cloud 创建“Web 应用”客户端。
  2. 允许的 JavaScript 来源填写 https://mu-wan.github.io，不附加路径。
  3. 添加测试用户，配置 drive.appdata 权限，并在同一项目启用 Google Drive API。
  4. 将客户端 ID 填入阅读器，通过系统浏览器选择 Google 账号并授权。授权后返回 Papery；无法返回时可粘贴加密连接码。
  5. 先在有书的设备同步，再在另一设备用同一客户端 ID 和 Google 账号同步。

开始之前

Android 安装包使用项目现有测试签名。关闭应用或授权过期后，Google Drive 需要重新连接；完整书库同步会增加大型 PDF 的传输流量。首次启动没有示例书籍和默认昵称，导入自己的书籍后即可开始阅读。
