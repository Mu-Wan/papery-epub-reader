Changes: select Chinese headwords (1-8 Han characters); convert headwords and definitions to Simplified Chinese with OpenCC 1.4.2 (t2s); merge duplicate simplified headwords; remove traditional lookup aliases; retain up to four Chinese definitions per headword; omit examples, quotations, media and pronunciation; remove repeated whitespace; resolve form redirects to canonical definitions; discard missing-definition and template placeholders; partition into shards. Build dependency: OpenCC 1.4.2 (https://github.com/BYVoid/OpenCC), licensed under Apache-2.0; used only during dictionary preparation, not included as a runtime component.
Rebuild: python -m pip install -r scripts/dictionary-requirements.txt
Then: python scripts/build-offline-dictionary.py --source <downloaded-jsonl>
The manifest records the original download URL and SHA-256.
